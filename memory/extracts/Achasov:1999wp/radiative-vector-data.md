This experimental report is a useful experiment-level provenance source for radiative light-vector decays, including $V\to P\gamma$ channels [@Achasov:1999wp]. In the fit, each partial width constrains the corresponding on-shell odd-parity amplitude squared, hence a channel-specific combination of $VJP$, $VVP$, photon-vector mixing, and any retained local term. The short conference report does not provide a reusable global covariance matrix; use it as a cross-check or as an input only after reconciling it with the PDG average.
