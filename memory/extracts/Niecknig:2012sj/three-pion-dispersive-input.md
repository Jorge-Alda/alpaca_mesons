The arXiv source archive is cached at `memory/sources/Niecknig:2012sj/arxiv-source.tar`. The dispersive analysis fits the $\phi\to3\pi$ Dalitz distribution and uses the partial width for normalization; it compares KLOE and CMD-2 data and predicts the $\omega\to3\pi$ Dalitz shape [@Niecknig:2012sj]. It is therefore a theory-interface reference for the first-release observables, not an independent experimental dataset. The reported fits use efficiency-corrected bins and statistical errors; no experimental covariance is provided by this paper.
