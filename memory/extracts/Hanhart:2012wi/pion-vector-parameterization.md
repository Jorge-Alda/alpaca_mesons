# Pion vector form factor

Hanhart's parameterization is built to implement the elastic two-pion phase and the associated analytic structure of the pion vector form factor. It is a dispersive alternative to a Breit--Wigner line shape and is especially relevant when an observable scans the rho region with precision. [@Hanhart:2012wi]

Within the elastic region, the form factor has the phase of the isovector P-wave scattering amplitude. A one-channel Omnes representation is

$$
F_V(s)=P(s) Omega(s),
$$

where $P(s)$ contains subtraction constants and left-hand or inelastic information not fixed by the elastic phase. [@Hanhart:2012wi]
