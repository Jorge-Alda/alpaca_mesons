# $a_1(1260)$ in RChT (Dumm:2009va)

- Lagrangian (Dumm:2009va, Eqs. ret, lag2): $\mathcal{L}_{R\chi T}=\tfrac{F^2}4\langle u_\mu u^\mu+\chi_+\rangle+\tfrac{F_V}{2\sqrt2}\langle V_{\mu\nu}f_+^{\mu\nu}\rangle+i\tfrac{G_V}{\sqrt2}\langle V_{\mu\nu}u^\mu u^\nu\rangle+\tfrac{F_A}{2\sqrt2}\langle A_{\mu\nu}f_-^{\mu\nu}\rangle+\mathcal{L}^V_{\rm kin}+\mathcal{L}^A_{\rm kin}+\sum_{i=1}^5\lambda_i\mathcal{O}^i_{VAP}$, with $\mathcal{O}^i_{VAP}$ as in the Cirigliano:2004ue extract.
- Spin-1 nonets use the antisymmetric tensor formulation, stated to be consistent with the $\chi$PT $\mathcal{O}(p^2)$ Lagrangian (Dumm:2009va, citing Ecker:1989yg).
- Large-$N_C$, one $V$ and one $A$ nonet (Dumm:2009va): $F_VG_V=F^2$; $F_V^2-F_A^2=F^2$, $F_V^2M_V^2=F_A^2M_A^2$ (Ecker:1988te); and the $\langle VAP\rangle$ values (Cirigliano:2004ue) $\lambda'=\frac{F^2}{2\sqrt2F_AG_V}=\frac{M_A}{2\sqrt2M_V}$, $\lambda''=\frac{2G_V-F_V}{2\sqrt2F_A}=\frac{M_A^2-2M_V^2}{2\sqrt2M_VM_A}$, $4\lambda_0=\lambda'+\lambda''$.
- Large-$N_C$ axial mass $M_A=998(49)$ MeV differs appreciably from the physical $a_1$ mass (Dumm:2009va, citing a literature fit not in this bibliography). Fit parameter sets: $F_V=0.180$, $F_A=0.149$ GeV and $F_V=0.206$, $F_A=0.145$ GeV (Dumm:2009va).
- Dressed propagator: $\Pi^{a_1}_{(0)}=-\frac{F_A^2}{M_{a_1}^2-Q^2}$, resummed $\Pi^{a_1}(Q^2)=-\frac{F_A^2}{M_{a_1}^2-Q^2+\Delta(Q^2)}$, $M_{a_1}\Gamma_{a_1}(Q^2)=-\mathrm{Im}\Delta(Q^2)$, $\Gamma_{a_1}(Q^2)=\frac{M_{a_1}^2-Q^2}{M_{a_1}\Pi^{a_1}_{(0)}}\mathrm{Im}\Pi^{a_1}_{(1)}$ (Dumm:2009va). The width is computed from $\pi\pi\pi$ and $K\bar K\pi$ intermediate states with explicit $1/F_A^2$ prefactors in the source; formulae not transcribed (unverified beyond the structure above).
