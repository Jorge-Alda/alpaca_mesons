# Selected measurements for the bounded odd-action calibration

The machine-readable selection is [odd_low_energy_measurements.json](../../../data/odd_parity/odd_low_energy_measurements.json). The official PDG 2024 particle listings are archived under [the PDG source index](../../sources/ParticleDataGroup:2024cfk/INDEX.md); the JSON records each source URL, local PDF, SHA-256, and printed page. Values are kept on the PDG 2024 convention to match the bibliography key [@ParticleDataGroup:2024cfk].

The selected branching fractions are $\omega\to\pi^0\gamma$: $(8.35\pm0.27)\%$ (page 3); $\rho^0\to\pi^0\gamma$: $(4.7\pm0.8)\times10^{-4}$ and $\rho^0\to\eta\gamma$: $(3.00\pm0.21)\times10^{-4}$ (page 11); $\omega\to\eta\gamma$: $(6.3\pm1.3)\times10^{-4}$ from the dedicated branching-ratio table's OUR AVERAGE (page 11); $\eta'\to\omega\gamma$: $(2.50\pm0.07)\%$ (page 7); and $\phi\to\eta\gamma$: $(1.26\pm0.04)\%$ (page 13). The two $K^*(892)\to K\gamma$ entries, $(2.46\pm0.21)\times10^{-3}$ and $(0.98\pm0.09)\times10^{-3}$ (page 10), are PDG constrained-fit outputs; no OUR AVERAGE is listed. Their correlated fit ingredients are not an independent direct measurement. The charged-rho mode has $\mathcal B(\rho^+\to\pi^+\gamma)=(4.5\pm0.5)\times10^{-4}$ (page 11). PDG consistency factors are not applied to the quoted errors a second time.

For the two-photon normalization, PDG cites the PrimEx value $\Gamma(\pi^0\to\gamma\gamma)=7.802\pm0.052\,({\rm stat})\pm0.105\,({\rm syst})\,{\rm eV}$ (page 2); the JSON combines these errors in quadrature and stores a partial width. This direct-width policy avoids adding the PDG mean-life average, which is derived from the same width information. The selected averages are $\Gamma(\eta\to\gamma\gamma)=0.516\pm0.018$ keV and $\Gamma(\eta'\to\gamma\gamma)=4.28\pm0.19$ keV (page 3 of each listing).

The total-width nuisance table stores each resonance width once for use with branching-fraction rows. The summaries are not jointly independent: PDG reports constrained fits and internal correlations for some channel sets, and the selected extract does not reconstruct the complete cross-channel covariance. Treating the quotes as diagonal is therefore only a conditional diagnostic approximation. The rho entries carry an additional broad-resonance limitation when compared with an on-shell narrow-width tensor predictor.

The inclusive PDG $\eta'\to\rho^0\gamma$ branching fraction is deferred: it includes non-resonant $\pi^+\pi^-\gamma$, while the listed resonant fractions come from component fits rather than a model-independent average. Hard spacelike TFF and three-pion inputs are outside this snapshot.
