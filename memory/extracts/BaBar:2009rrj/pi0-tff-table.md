The arXiv source archive is cached at `memory/sources/BaBar:2009rrj/arxiv-source.tar`. Table 11 gives binned $Q^2F_{\pi^0\gamma^*\gamma}(Q^2)$ values and quotes statistical and systematic uncertainties; the paper's fit uses the $Q^2$ dependence to test the transition-form-factor shape [@BaBar:2009rrj]. In the minimal likelihood these are diagonal points, because the source archive provides no covariance matrix. The observable constrains the $\pi^0$ TFF normalization and high-$Q^2$ slope/curvature combinations, not an individual RChT coupling.
The 17 Table 11 rows are in [`data/odd_parity/babar_pi0_table11.csv`](../../../data/odd_parity/babar_pi0_table11.csv); the final two $Q^2F$ errors retain the published asymmetric magnitudes $(40,33)$ and $(45,39)$ MeV. The versioned likelihood records the authorized eventual diagonal rule $\sigma=(\sigma_-+\sigma_+)/2$ while preserving those raw columns, and records the separate normalization nuisance prescription.
